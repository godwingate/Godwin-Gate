# Godwin Gate Website

A responsive, static multi-page website for Godwin Gate, built with plain HTML, CSS, and JavaScript. No build tools or package installation are required.

## Files

- `index.html` — Home page
- `about.html` — About page
- `projects.html` — Projects portfolio
- `contact.html` — Contact page
- `styles.css` — Shared responsive styling
- `script.js` — Mobile navigation toggle

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload all files and folders from this project. Make sure `index.html` is in the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** in the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.
