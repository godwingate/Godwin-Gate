# Godwin Gate Website

A responsive static website for Godwin Gate, built with HTML, CSS, and JavaScript and suitable for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — About Godwin Gate
- `projects.html` — Newsletter portfolio examples: welcome email, release announcement, series launch, and multi-author promotion
- `contact.html` — Contact

## Publish on GitHub Pages
1. Upload all files and folders in this package to your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**, select your main branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.

## Newsletter example images
The four portfolio previews currently reference the image URLs supplied from the Lovable project. For long-term reliability, download those images and store them in this repository, then update the image URLs to local paths.
